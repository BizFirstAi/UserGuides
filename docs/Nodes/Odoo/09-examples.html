Examples

A worked website-lead-to-opportunity workflow, end to end

Scenario: a lead comes in from a website contact form. The workflow records the contact, creates a CRM lead, watches for changes to it, schedules a follow-up call, and eventually closes it won or lost.

Step 1 — Create the Contact

resource: contact, operation: create

{
  "fields": {
    "name": "Jordan Lee",
    "email": "jordan.lee@example.com",
    "phone": "+1-555-0142",
    "is_company": false
  }
}

Returns a contactID. Carry it forward to the next step.

Step 2 — Create the Lead, Linked to That Contact

resource: lead, operation: create

{
  "fields": {
    "name": "Website inquiry — Jordan Lee",
    "type": "lead",
    "partner_id": { "id": "<contactID from Step 1>" },
    "expected_revenue": 5000,
    "source_id": { "id": "<utmSource lookup ID for "Website">" }
  }
}

Resolve source_id beforehand with a lookup / utmSource call if you don't already have the ID cached — see Lookup Tables.

Step 3 — React to New/Changed Leads with the Trigger

resource: trigger

{
  "targetResource": "lead",
  "domain": {
    "topLevelOperator": "and",
    "groups": [
      { "operator": "and", "conditions": [
        { "field": "type", "operator": "=", "value": "lead" }
      ]}
    ]
  },
  "pollIntervalSeconds": 300,
  "pageSize": 100
}

The type = lead condition keeps this trigger from also firing on opportunity changes — remember crm.lead holds both. See Trigger / Polling for the first-cycle seed behavior and delivery guarantees.

Step 4 — Schedule a Follow-Up Call

resource: activity, operation: create

{
  "resModel": "crm.lead",
  "resID": "<leadID from the trigger event>",
  "activityTypeID": "<activityType lookup ID for "Call">",
  "fields": {
    "summary": "Initial qualification call",
    "date_deadline": "2026-08-05"
  }
}

Step 5a — Qualified: Convert to Opportunity

resource: lead, operation: convert

{
  "leadID": "<leadID>",
  "userID": "<salesperson user ID>",
  "teamID": "<team lookup ID>"
}

Check the applied field in the result — see Leads & Opportunities for why a success: true, applied: false response is not a bug.

Step 5b — Not Qualified: Mark Lost

resource: lead, operation: markLost

{
  "leadID": "<leadID>",
  "lostReasonID": "<lostReason lookup ID for "Not enough budget">"
}

Step 6 — Log the Outcome on the Chatter

resource: lead, operation: logNote

{
  "leadID": "<leadID>",
  "noteBody": "Auto-logged by workflow: qualification call completed, converted to opportunity."
}
