The Domain Filter Shape

A domain is one or more groups of conditions, combined by a top-level AND/OR operator:

{
  "topLevelOperator": "and",
  "groups": [
    {
      "operator": "or",
      "negate": false,
      "conditions": [
        { "field": "stage_id.name", "operator": "=", "value": "Won", "negate": false },
        { "field": "probability", "operator": ">=", "value": 70, "negate": false }
      ]
    }
  ]
}

This two-level structure (groups of conditions, groups combined by one operator) expresses any domain in disjunctive or conjunctive normal form — "(stage is Won OR stage is Negotiation) AND probability >= 50", or "NOT (lost_reason is Price AND team is EMEA)" — without needing arbitrary nesting depth in the UI. An empty domain is legitimate and means match-all.

Operators

OperatorMeaning
=Equal
!=Not equal
> / < / >= / <=Comparison
likeSubstring match, case-sensitive
in / not inValue is a list
child_ofHierarchical descent — e.g. all contacts under a parent company

Field names may traverse relations with dot notation (stage_id.name, country_id.code) — Odoo resolves the join server-side. Set negate: true on a condition or group to wrap it in Odoo's NOT.

Output Shape

Every record — on create, get, getMany, or a trigger event — is flattened to a plain object: id plus every requested/normalized field, ready to reference directly in a downstream node ({{ $json.name }}, {{ $json.stage_id.displayName }}). Relation fields (many2one) are always { "id": ..., "displayName": ... }, never Odoo's raw [id, "name"] tuple.

Write Results — applied vs. Success

Update, Delete, Mark Won, Mark Lost, and Convert all return applied alongside success. These are not the same thing — see Leads & Opportunities for the one case (Convert on an already-won/lost lead) where a call reports success with applied: false and a warning, because Odoo itself gives no other way to detect a silently skipped action.

Errors

Failures never throw — they come back as a result with success: false, a stable errorCode, and a human-readable errorMessage that never contains credential material. See Troubleshooting for the full code reference.
