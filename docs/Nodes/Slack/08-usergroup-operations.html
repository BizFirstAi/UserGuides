User Group Operations

resource: userGroup — 7 operations for managing Slack user groups (subteams)

Underlying API: Slack's usergroups.* Web API methods.

create

Creates a new user group via usergroups.create.

FieldRequiredNotes
nameYesDisplay name of the group.
handleNo@-mention handle.
descriptionNoGroup description.
channelsNoComma-separated channel IDs the group defaults into.

update

Updates group fields via usergroups.update. Only non-null fields are sent.

FieldRequiredNotes
userGroupIdYesTarget group.
name, handle, descriptionNoFields to change; omitted fields keep their current value.

enable / disable

enable (usergroups.enable) and disable (usergroups.disable) both take a single required field: userGroupId.

getMany

Lists all user groups via usergroups.list.

FieldRequiredDefaultNotes
includeDisabledNofalseInclude disabled groups in the results.
includeCountNotrueInclude each group's member count.

getUsers

Lists the members of a group via usergroups.users.list.

FieldRequiredNotes
userGroupIdYesTarget group.
includeDisabledNoInclude members whose accounts are disabled.

addUsers

Sets the full membership list — usergroups.users.update is a replace operation, not an append. Existing members not included in userIds are removed from the group.
FieldRequiredNotes
userGroupIdYesTarget group.
userIdsYesComma-separated Slack user IDs — becomes the complete membership list.
