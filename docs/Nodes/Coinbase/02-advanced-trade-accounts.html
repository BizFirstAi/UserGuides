Advanced Trade: Accounts

resource: accounts — brokerage account balances (ACC01–ACC02)

list (ACC01)

Returns every brokerage account on the credential. No operation-specific config keys.

Example response:

{
  "items": [
    {
      "accountUUID": "8bfc20d7-...",
      "name": "BTC Wallet",
      "currency": "BTC",
      "availableBalance": "1.23456789",
      "hold": "0",
      "active": true,
      "default": false,
      "type": "ACCOUNT_TYPE_CRYPTO",
      "ready": true,
      "createdAt": "2024-01-15T10:00:00Z"
    }
  ]
}

get (ACC02)

Returns a single account record, same shape as list.

FieldRequiredDescription
accountId✓ YesThe brokerage account UUID to look up.
list vs. get: Use list to enumerate all accounts under the credential (e.g. to find an accountId by currency). Use get once you already have the UUID.
