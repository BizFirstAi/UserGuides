Server Wallet: Solana Account

resource: solanaAccount — CDP-managed Solana accounts (SOL01–SOL02)

getOrCreate (SOL01)

Returns an existing Solana account by name, or creates it if it doesn't exist yet.

FieldRequiredDescription
accountName✓ YesA stable name identifying this account within your CDP project.

Output: single Solana account record.

requestFaucet (SOL02) wallet secret required, fail-closed/unconfirmed

Requests testnet funds from Coinbase's Solana faucet.

FieldRequiredDescription
address✓ YesSolana address to fund.
token✓ YesToken to request.

Testnet-only. Output: same shape as account/requestFaucet.

Wallet Secret required, but unconfirmed — same fail-closed reasoning as account/requestFaucet. See Configuration.
