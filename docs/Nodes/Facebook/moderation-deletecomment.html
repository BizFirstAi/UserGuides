moderation/deleteComment

Permanently delete a comment from a Facebook post. Irreversible — there is no undo through the node, the API, or Facebook.

Permanently irreversible. A deleted comment cannot be recovered — not through this node, not through the Facebook interface, not by Meta support. There is no confirmation step and no undo. Before automating this, be certain a false positive in your screening rules is an acceptable cost. In almost every case moderation/hideComment is the better default, because it is reversible.
Palette name: Delete Facebook Comment  ·  Graph call: DELETE /{commentId}  ·  Permissions: pages_manage_engagement  ·  Field reference: Moderation

When to Use

Reserve deletion for content that must not remain visible even to its author's friends:

  • Abuse, harassment, or hate speech that breaches your community policy.
  • Malicious links — phishing, malware, or scam URLs posted to your audience.
  • Doxxing or leaked personal data exposed in a public comment.
  • Content removal requests where a legal or compliance obligation requires the material to be gone rather than hidden.
  • Cleanup of your own automated comments published in error by a workflow.

For everything else — spam, off-topic replies, competitor promotion, comments awaiting review — hide instead.

Configuration

FieldRequiredDescription
resourceRequiredMust be moderation.
operationRequiredMust be deleteComment.
pageAccessTokenRequiredPage access token, or a stored credential. Minimum 100 characters.
commentIdRequiredThe comment to delete permanently.

This operation does not read pageId, and takes no other options — there is nothing to soften its effect.

{
  "resource": "moderation",
  "operation": "deleteComment",
  "credentialID": 4021,
  "commentId": "122099783774252226_966580579776255"

Building This Safely

  1. Capture the comment first. Store the text, author, timestamp, and ID before deleting. Once the call succeeds, that record is the only copy you will ever have.
  2. Gate it behind human approval for anything short of unambiguous abuse. An Approval node in front of this one turns an irreversible automated action into a reviewed one.
  3. Two-stage moderation. Hide immediately so the content is off the public post, then delete later after review. This gets the fast protective effect without the irreversible step.
  4. Log every deletion with the rule that triggered it, for audit and for tuning false positives.
  5. Test on a throwaway Page. Never rehearse this operation against a production Page.

Notes and Cautions

  • Effectively idempotent, but noisy. Deleting an already-deleted comment returns FACEBOOK_NOT_FOUND on the error port rather than succeeding quietly. Handle that case if you retry.
  • Deleting a comment removes its replies. Any thread hanging off it goes too.
  • The author is not told, but they will notice the comment is gone from their own view — unlike hiding, which is invisible to them.
  • Run destructive tests last. Sequence any test plan so deletion comes after every read and write you still need the data for.
