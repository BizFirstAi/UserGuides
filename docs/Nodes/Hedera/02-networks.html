Networks

mainnet, testnet, and previewnet — their URLs, how the default resolves, and how to add another.

Built-In Networks

NetworkDefault?Mirror Node REST URL
mainnet—https://mainnet-public.mirrornode.hedera.com
testnetDefaulthttps://testnet.mirrornode.hedera.com
previewnet—https://previewnet.mirrornode.hedera.com

All three are free, public, community-operated Mirror Nodes maintained for the Hedera ecosystem. No API key is needed to query them.

How the Default Resolves

When a node configuration omits the network field, the executor reads Hedera:DefaultNetwork from application settings and uses that network's MirrorRestUrl. Out of the box this is set to testnet, so a bare configuration like:

{
  "resource": "utility",
  "operation": "validateAddress",
  "address": "0.0.1234567"
}

runs against testnet without any explicit network field. To target a different network for a specific call, set network explicitly:

{
  "resource": "account",
  "operation": "getBalance",
  "network": "mainnet",
  "accountId": "0.0.1234567"
}

Adding a Custom or Additional Network

The Hedera:Networks section is a plain dictionary — add any additional entry to make it selectable from the network config key. This is useful for pointing at a self-hosted Mirror Node, a regional mirror, or a future Hedera network.

"Hedera": {
  "DefaultNetwork": "testnet",
  "Networks": {
    "mainnet":    { "MirrorRestUrl": "https://mainnet-public.mirrornode.hedera.com" },
    "testnet":    { "MirrorRestUrl": "https://testnet.mirrornode.hedera.com" },
    "previewnet": { "MirrorRestUrl": "https://previewnet.mirrornode.hedera.com" },
    "myMirror":   { "MirrorRestUrl": "https://hedera-mirror.internal.example.com" }
  }
}

Once added, reference it by name from any Hedera node configuration:

{
  "resource": "topic",
  "operation": "getMessages",
  "network": "myMirror",
  "topicId": "0.0.987654"
}
Names must match exactly. network and Hedera:DefaultNetwork are matched against the keys under Hedera:Networks as configured — there is no built-in fallback or fuzzy matching. A typo, or a network referenced before it's added to the section, fails fast rather than silently querying the wrong endpoint. See Troubleshooting.

Testnet Faucet

Because testnet is the default network and the natural place to build and test workflows, it's worth knowing that Hedera provides a free public testnet faucet. It dispenses test HBAR to any testnet account so you can experiment with balances, token transfers, and topic activity without spending real value. Use it to fund an account you control before wiring up examples like the ones in Examples.

Tip: Test HBAR from the faucet has no monetary value and only exists on testnet — it cannot be used against mainnet or previewnet endpoints, and testnet balances are unrelated to any mainnet account with the same ID format.
