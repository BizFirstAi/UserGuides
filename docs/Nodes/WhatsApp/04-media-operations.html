Media Operations

resource: media — upload, download, delete, and inspect media

upload

Uploads a file to WhatsApp's media store and returns a reusable media ID.

FieldRequiredDescription
fileBase64✓ YesBase64-encoded file content. Decoded by the executor before upload.
fileNameNoOriginal filename.
mimeTypeNoMIME type (e.g. image/jpeg).

download

Resolves a media ID to a downloadable URL and downloads the bytes.

FieldRequiredDescription
mediaId✓ YesMedia ID returned by a prior upload or received via webhook.

delete

Deletes an uploaded media object.

FieldRequiredDescription
mediaId✓ YesMedia ID to delete.

get-info

Returns metadata for a media object without downloading it.

FieldRequiredDescription
mediaId✓ YesMedia ID to inspect.
16 MB upload limit: MaxMediaUploadSizeBytes (default 16 MB) mirrors WhatsApp's own per-file limit. Larger files are rejected client-side before the upload request is even sent. See Configuration.
Media IDs expire: WhatsApp media IDs are only valid for a limited time after upload or receipt. Don't cache a mediaId for long-term reuse — re-upload or re-fetch as needed.
