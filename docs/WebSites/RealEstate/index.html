RealEstate

BizFirst's industry-vertical data platform for property listings — portable across CRM providers, designed to pair with Odoo (or a similar CRM/ERP) rather than duplicate it.

Industry vertical, not a CRM. RealEstate owns the property/listing domain (addresses, pricing, RESO/MLS fields, media, features) entirely itself, so it stays portable across CRM providers. It is not a community node wrapping a third-party API — it's a full BizFirst product with its own BizFirst.Ai.RealEstate.{Domain,Service,Infrastructure,Api,Api.Base} layers and its own RealEstate_* database schema.

What it does

RealEstate models the core real-estate listing entity (Property) with RESO-aligned fields (address, geo, price, beds/baths, lifecycle dates), a lightweight local Agent directory, content-addressed PropertyMedia (photos, floor plans, virtual tours, documents — bytes live in BizFirst's existing CID object store, never in this table), typed PropertyFeature flags (Boolean/Text/Number), and the supporting lookup/code-list tables (Property Types & Categories, Listing Types & Statuses, Media Types, Feature Types).

RealEstate + Odoo

Every Property can optionally link to a record in an external CRM via ExternalProviderID + ExternalRecordID. RealEstate_ExternalProviders is seeded with Odoo ("Self-hosted Odoo Community CRM") as its first row — the flagship integration target, reachable through the Odoo community node's Contact/Lead CRM capabilities. RealEstate is the industry-specific data layer; Odoo (or another provider registered the same way) is the CRM layer it links out to. See Connecting to Odoo & CRM for the full picture.

Quick Start

Register the module in an ASP.NET Core host: 

builder.Services.AddRealEstateInfrastructure(builder.Configuration); // binds "RealEstateDatabase" (falls back to "DefaultConnection")
builder.Services.AddRealEstateServices();

Every endpoint lives under api/v1/realestate/* (Properties, Agents, PropertyMedia, PropertyFeature, ExternalProviders, and five lookup resources), JWT-authenticated with realestate:read / realestate:write / realestate:full claim-based policies.
