Examples

A worked end-to-end flow: import → media → features → CRM link → search

1. Import an MLS listing

POST /api/v1/realestate/properties/create-listing

{
  "mlsNumber": "MLS-2026-004821",
  "propertyTypeID": 1,          // Residential
  "propertyCategoryID": 3,      // Single Family (must belong to PropertyTypeID 1)
  "listingTypeID": 1,           // For Sale
  "listingStatusID": 2,         // Active
  "addressLine1": "412 Maple Grove Ln", "city": "Austin", "stateProvince": "TX",
  "postalCode": "78704", "country": "USA",
  "listPrice": 649000, "bedrooms": 4, "bathrooms": 2.5, "squareFootage": 2380,
  "publicRemarks": "Beautifully updated craftsman close to downtown.",
  "privateRemarks": "Lockbox code 4471. Tenant occupied until the 15th.",
  "listAgentName": "Dana Whitfield", "listAgentMlsId": "TX-88213", "listOfficeName": "Whitfield Realty Group"
}

Response returns the new PropertyID. Note listAgentID is still null — the raw feed values are captured, but nothing has matched them to a local Agent row yet.

2. Attach photos

Upload the bytes to BizFirst's object store first (outside this API), then attach each by CID:

POST /api/v1/realestate/property-media/attach
{ "propertyID": 4821, "mediaTypeID": 1, "mediaCID": "bafy...front-exterior", "displayOrder": 0 }

PATCH /api/v1/realestate/property-media/primary
{ "propertyMediaID": 9001 }   // promotes it to the gallery hero image

3. Tag features

Save a whole checklist in one call:

POST /api/v1/realestate/property-features/set-many
{
  "propertyID": 4821,
  "features": [
    { "featureTypeID": 10, "featureValue": "1" },     // Pool (Boolean)
    { "featureTypeID": 11, "featureValue": "2" },      // GarageSpaces (Number)
    { "featureTypeID": 12, "featureValue": "Granite countertops, tankless water heater" } // Text
  ]
}

4. Match the listing agent, then link the property to Odoo

POST /api/v1/realestate/agents/match
{ "listAgentMlsId": "TX-88213", "listAgentName": "Dana Whitfield", "listOfficeName": "Whitfield Realty Group", "createIfNotFound": true }
// -> { agentID: 55, wasAmbiguous: false, wasCreated: true }

PATCH /api/v1/realestate/properties/listing-agent
{ "propertyID": 4821, "listAgentID": 55 }

PATCH /api/v1/realestate/properties/external-link
{ "propertyID": 4821, "externalProviderID": 1, "externalRecordID": "odoo-crm-lead-9931" }

externalRecordID here is the id of the corresponding record over in Odoo — created/found via the Odoo community node's Lead/Contact operations in a workflow, not by RealEstate itself.

5. Consumer search

POST /api/v1/realestate/properties/search
{ "city": "Austin", "minBedrooms": 3, "maxListPrice": 700000, "listingStatusID": 2 }

6. Close the deal

PATCH /api/v1/realestate/properties/listing-status
{ "propertyID": 4821, "listingStatusID": 6, "closeDate": "2026-08-14" }  // Sold, with an explicit close date
