Input & Output

Request/response shapes worth knowing before you integrate

CreateListingRequest

The full listing-create payload (POST /create-listing):

{
  "mlsNumber": "string?",
  "propertyTypeID": 0,
  "propertyCategoryID": 0,      // optional — validated against propertyTypeID server-side
  "listingTypeID": 0,
  "listingStatusID": 0,
  "addressLine1": "string", "addressLine2": "string?",
  "city": "string", "stateProvince": "string", "postalCode": "string", "country": "string",
  "latitude": 0.0, "longitude": 0.0,
  "parcelNumber": "string?",
  "listPrice": 0.0, "rentAmount": 0.0,
  "associationFee": 0.0, "associationFeeFrequency": "Monthly|Quarterly|Annually|OneTime",
  "bedrooms": 0, "bathrooms": 0.0, "squareFootage": 0, "lotSizeSqFt": 0,
  "yearBuilt": 0, "garageSpaces": 0, "storiesTotal": 0,
  "publicRemarks": "string?", "privateRemarks": "string?",
  "listAgentName": "string?", "listAgentMlsId": "string?", "listOfficeName": "string?"
}

Note there is no externalProviderID/externalRecordID on create — link a listing afterward via PATCH /external-link (see Connecting to Odoo & CRM).

Lifecycle operation payloads

RequestShape
ReclassifyPropertyRequest{ propertyID, propertyTypeID, propertyCategoryID? } — both travel together, must stay consistent
UpdateListingStatusRequest{ propertyID, listingStatusID, onMarketDate?, closeDate? } — dates are caller-driven, not inferred from status
UpdateListPriceRequest{ propertyID, listPrice } — OriginalListPrice untouched
LinkExternalRecordRequest{ propertyID, externalProviderID, externalRecordID }
AssignListingAgentRequest{ propertyID, listAgentID? } — null clears the attribution
UpdateRawListingDataRequest{ propertyID, rawListingDataJson? }

Standard envelope

List/search endpoints return the platform-standard GoWebStandardListResponse / GoWebStandardSearchResponse paged envelope; single-record fetches return GetByIdWebResponse<T>; mutations return InsertWebResponse, UpdateWebResponse, or DeleteWebResponse as appropriate — the same conventions used across BizFirst's other APIs.
